# 管理后台

入口：导航抽屉「🛠️ 管理后台」→ `/admin/entry`（只有 `is_owner` 可见）。
所有后台路由都在服务端校验权限，**前端隐藏按钮只是体验优化，不是安全边界**。

![后台首页](../screenshots/admin-dashboard.webp)

## 1. 用户管理 `/admin/users`

| 操作 | 说明 |
|---|---|
| 查看成员列表 | 用户名、QQ、邮箱、加入时间、身份 |
| 删除用户 | 谨慎；会级联清理其帖子/回复/通知等 |
| 设为/取消运营 | `is_staff` 开关 |
| 设为/取消站长 | `is_owner` 开关（别把自己锁在门外） |
| 绑定/修改邮箱 | 用于找回密码 |
| 重置密码 | 生成新密码（线下告知对方） |
| 导出 Excel | 用 openpyxl 导出成员表 |

## 2. 帖子管理 `/admin/messages`

- 查看全部帖子与回复，删除违规内容。
- 删除帖子时连带删除其回复。
- 这里也能看到 AI 好友的用量入口（见第 6 节）。

## 3. 活动管理 `/admin/activities/*`

- 新增/编辑/删除社团活动（`activity` 表），会展示在「近期活动」页和社团简介的数据条里。
- 字段：标题、日期（字符串 `YYYY-MM-DD`）、内容。

## 4. 赛事管理 `/admin/contests/*`

| 路由 | 作用 |
|---|---|
| `manage` | 赛事列表 + 批量操作 |
| `create` / `edit` | 创建/编辑赛事：标题、类型、分组方式、各阶段天数、起止时间 |
| `delete` | 删除赛事（连带提名/候选/投票） |
| `nominations/approve` / `reject` | 提名审核 |
| `candidates/ban` / `unban` | 角色禁赛/解禁 |
| `candidates/delete` | 删除候选角色 |

!!! warning "赛制参数改动的影响"
    改阶段天数会影响"当前阶段"的判定，正在进行的赛事**不要改**，否则倒计时和晋级会乱。要调整就等本届结束或新建一届。

## 5. 照片墙管理 `/admin/gallery`

- 上传图片（自动压缩）、删除图片（同时删 Storage 对象）。

## 6. AI 好友管理 `/admin/ai_friend`

- 统计：自定义角色数、公开角色数、已下架数、今日消息数。
- 模型调用分布：哪个免费模型回答了多少条（`FAQ 兜底 / 未调用模型` 单独统计）。
- 角色审核：可下架/恢复用户创建的人设；下架后聊天选择列表里不再出现。
- 说明文案里明确写着：**AI 对话只调用免费模型，全部失败回落 FAQ，不会产生付费调用**。

## 7. 通知群发 `/admin/notifications/send`

- 给全体或指定成员发 `system` 类型通知。
- 通知会出现在通知中心，并按用户的免打扰设置决定是否发邮件。

## 8. 操作日志 `/admin/logs`

后台所有**写操作都会自动留痕**（不用手写代码）：删除帖子/回复/用户、权限变更、绑定邮箱、
重置密码、活动增删改、照片上传删除、赛事创建/编辑/删除、提名审核、角色禁赛、群发通知、AI 人设审核。

| 字段 | 说明 |
|---|---|
| 时间 | 东八区展示 |
| 操作者 | 用户名（冗余存一份，用户被删也能追溯） |
| 动作 | 人类可读的动作名，如「删除帖子」「通过提名」 |
| 目标 | 路径参数，如 `message_id=12` |
| 详情 | 关键表单内容摘要（标题/正文前 300 字）或请求路径 |
| IP | 操作来源 IP |

实现方式：`admin` 蓝图的 `after_request` 钩子统一记录「已登录 + staff/owner + POST + 非 4xx/5xx」的请求，
日志写入失败只会回滚日志本身，**绝不影响正常操作**。

> 用途：删错东西、误封账号、争执复盘时能查「谁在什么时候动了什么」。

## 9. 运营快捷入口 `/staff/dashboard`

比管理后台轻量的审核面板：处理提名、看当天数据。`is_staff` 即可进入。

## 10. 常见后台误操作

| 操作 | 后果 | 补救 |
|---|---|---|
| 删用户 | 级联删其帖子/回复/通知 | 只能从数据库备份恢复 |
| 删赛事 | 连带提名/候选/投票全没 | 从备份恢复 |
| 改进行中赛事的天数 | 阶段判定错乱 | 改回原值；或结算后重建 |
| 取消自己的 owner | 立刻失去后台 | 让另一个 owner 重新授权，或直接改库 |
